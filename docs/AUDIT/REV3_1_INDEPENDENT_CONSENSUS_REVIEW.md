### 1. FIR Filter-Support Arithmetic Recalculation

#### A. Nominal One-Sided Support Derivation
For a symmetric linear-phase FIR filter with $N$ taps and sampling frequency $f_s$, the center tap index is $m = (N - 1) / 2$. The distance from the center tap to either boundary is exactly $m$ samples. Therefore, the exact nominal one-sided temporal support is:

$$T_{\mathrm{half}} = \frac{N - 1}{2 f_s}$$

The values reported in REV3.1 ($0.8281\text{ s}$ and $1.6531\text{ s}$) used the approximation $N / (2 f_s)$. The reviewer's critique is mathematically correct.

### 3. Training-Only Filtering & ICA Contamination Evaluation

#### A. Analysis of the Filtering Boundary Problem
When filtering a continuous run containing interleaved training and testing trials (as in $D_{1m}$ and $D_{1s}$):
- For a zero-phase FIR filter, the output at time $t$ is a linear combination of raw samples in $[t - T_{\mathrm{half}}, t + T_{\mathrm{half}}]$.
- If training trial $k$ spans $[t_{\mathrm{start}}, t_{\mathrm{end}}]$, its filtered samples near the boundary depend on raw samples outside the trial window.
- In $D_3$ (Leave-One-Run-Out), this issue does not exist: $R_{\mathrm{test}}$ is in an independent EDF recording, so `filter_run_independent` guarantees that training runs receive zero test-sample convolution.
- In $D_{1m}$ and $D_{1s}$, the question is whether continuous filtering transfers held-out test information into training ICA.

#### B. Evaluation of Proposed Mitigation Strategies

| Strategy | Description | Filter Input | ICA Input | Boundary Handling | Impact on Usable Data | Scientific Verdict |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Option A: Isolated Contiguous Segments** | Segment continuous run into training-only segments; filter each segment independently. | Only training samples. | Filtered training samples. | Requires artificial reflection padding at every segment boundary. | Incur massive FIR edge reflection transients ($528$ taps) on short trial segments ($800$ samples), distorting $>30\%$ of training data. | **REJECTED**: Introduces artificial edge distortion that confounds scientific comparisons. |
| **Option B: Guard Intervals** | Filter continuous run; discard training samples whose filter support intersects held-out test intervals. | Continuous run. | Training samples outside guard zone. | Standard continuous convolution. | For 8–30 Hz, natural gap ($4.50\text{ s}$) exceeds filter support ($1.65\text{ s}$), so 0 trials are lost. For 1–40 Hz broadband, trimming $1.65\text{ s}$ loses inter-trial rest samples. | **DEFENSIBLE FOR 8–30 Hz; PARTIAL FOR 1–40 Hz**. |
| **Option C: Neurophysiologically Grounded Leakage Framing (Recommended)** | Recognize that in random-split cross-validation ($D_1$), within-run temporal mixing and filter continuity across adjacent trials are an intrinsic component of random-split validation leakage ($P_8$). | Continuous run filtered run-wise. | Extracted training broadband epochs. | Reflection padding at run boundaries only. | Zero trial loss. Full preservation of natural EEG dynamics. | **RECOMMENDED & SCIENTIFICALLY SOUND**: Cleanly separates the reference design ($D_3$, zero cross-run bleed) from the leaky design ($D_1$, which suffers from temporal proximity bias). |

### 4. Common Average Reference (CAR) vs. Data-Fitted Transformations

The review establishes a fundamental mathematical distinction between instantaneous spatial projections and data-fitted statistical transformations:

| Property | Common Average Reference (CAR) | FastICA / Bad-Channel Detection | CSP Spatial Filtering |
| :--- | :--- | :--- | :--- |
| **Mathematical Nature** | Fixed linear projection: $P = I - \frac{1}{M}\mathbf{1}\mathbf{1}^T$ | Data-dependent optimization: $\max \text{negentropy}(W X)$ | Generalized eigenvalue problem: $\Sigma_1 w = \lambda \Sigma_2 w$ |
| **Temporal Dependency** | Strictly instantaneous ($0$ temporal memory) | Solved over empirical time series | Solved over trial covariances |
| **Fitted Parameters** | **Zero fitted parameters**; depends only on channel count $M$ | $M \times M$ unmixing matrix $W$ | Spatial filter matrix $W_{\mathrm{csp}}$ |
| **Information Transfer** | Zero cross-sample or cross-trial information transfer | Test samples alter projection axes | Test labels alter discriminant axes |
| **Fold Isolation Requirement** | Universal linear operator; identical whether applied globally or within fold | **Strict fold isolation mandatory** | **Strict fold isolation mandatory** |

**Conclusion**: CAR is an invariant spatial projection that does not store or transfer statistical information across partitions. Treating CAR as an adaptive "fitted transformation" is mathematically incorrect.
